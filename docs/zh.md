# dsh-mcp-manager

[English](../README.md) | 简体中文

通过 DSH 原生客户端和 profile 配置管理 MCP 服务。

## 安装与入口

本地验证后，通过桌面应用的官方插件管理器安装此目录。日常使用从「设置 → MCP 管理」进入，插件详情保留同一面板作为备用入口；两处使用同一后端和 profile 配置。设置入口通过官方 `settings.section` 插槽注册，不注入宿主 DOM。不要另起 Web profile 或手改覆盖 profile 文件。Host 代码更新可能需要完整重启应用；重启前应协调正在进行的会话。

## 功能

- 服务卡片及描边/主按钮使用官方设置页主题样式，仅以简洁徽标展示状态，不公示内部检查时间和解释性说明；外部服务明确只读、未检测。
- 粘贴严格的 `mcpServers` JSON，预览后导入，默认停用。
- 使用原生 stdio 和 Streamable HTTP；`type: http` 自动转换。
- 启用、停用、删除或显式替换本插件管理的服务配置。
- 替换时可保留现有 headers/env，不将其原值返回浏览器。
- 只读列出其他来源声明、可寻址的原生 MCP 条目。
- 展示全局已注册 MCP 工具名称；这不是连接健康检查。

示例（使用自己的密钥，禁止提交真实凭据）：

```json
{"mcpServers":{"utools":{"type":"http","url":"http://127.0.0.1:3501/mcp","headers":{"x-mcp-key":"YOUR_KEY"}}}}
```

粘贴、预览并确认导入后，服务处于停用状态。启用 stdio 前应检查原始配置中的命令：启用会由原生 MCP 客户端执行该命令。连接 uTools HTTP 服务时保持 uTools 运行。目前编辑采用明确的替换 JSON，而非逐字段表单；替换必须保留原服务名称，保存后服务停用；重新启用前会显示已保存的命令及参数供确认。勾选「保留 headers/env」时，替换 JSON 必须省略相应字段。

## 所有权与安全

DSH profile 中本插件的 `servers` 字段是所管服务唯一的持久化来源。写入通过官方 `configEditor`，启用的服务通过官方 `dsh-mcp-client` 子插件运行。不创建旁路注册表、独立传输或守护进程。其他插件的服务仍归其原所有者管理。

HTTP 路由必须经过 DSH 签名 Peer 认证和意图头校验。响应不缓存。列表不返回凭据值、URL 路径/查询参数或命令参数。错误不返回上游诊断原文。导入拒绝未知字段、重复键、危险对象键和名称冲突，限制为 1 MiB、100 个服务。写入须确认，且在串行配置回调内再次检查版本基线。

## 限制

- 保存管理配置会重载整个子树，重连**本插件管理的全部已启用服务**，可能中断在途工具调用。
- 原生客户端没有可靠的公开实时健康接口。管理页面打开、保存启用后、页面恢复可见及可见期间每 60 秒自动经官方工具执行链，在现有原生连接上调用 `resources/list`，无需额外点击；停用服务不检查，隐藏页面暂停，关闭页面释放定时器。同一面板串行检查且不重叠，仅在内存保存成败与时间。手动「刷新」可立即重试。这是历史结果，不保证持续在线；不支持资源的服务即使业务工具可用，也可能检查未通过。插件重载会清空检查记录。工具名称为全局视图，不是某个 Agent 可见的完整清单，也不能可靠反推服务归属。
- 名称预检只是尽力检查的快照；原生作用域注册保留最终裁决。影响 stdio 执行的环境变量覆盖需要在本 UI 外人工审查；导入不执行命令、不展开表达式。
- 此预览版本中外部条目只读；`configEditor.entries()` 可能不返回未激活或不可寻址条目。
- 不支持 OAuth、旧式 SSE、市场、自动调用业务工具或自动迁移。
- 完整替换会明确替换省略的非秘密字段。导入格式不支持配置表达式。
- headers/env 由宿主存于 profile，不提供额外加密凭据库。
